# 🚀 House of Vibes — Official Agency Website

Welcome to the official web application repository for **House of Vibes**, a cutting-edge IT Solutions, Software Engineering, Mobile App & AI Development agency based in Ahmedabad, India.

---

## ✨ Features

- **🌐 6-Page Modern Architecture:**
  - `Home`: Animated hero section, live counters, tech stack filter, testimonials, and high-conversion CTAs.
  - `About Us`: Company story, engineering culture, core values, and interactive workflow roadmap.
  - `Services`: Enterprise Software, Web & Mobile Development, AI & ML Solutions, Cloud/DevOps, and UI/UX.
  - `Portfolio`: Filterable case study showcase with dynamic detail drawers.
  - `Careers`: Company perks and filterable job listings with working application modals.
  - `Contact`: Project cost estimator form, interactive Google Map, and direct call/WhatsApp integration.
- **⚡ High-Performance Tech Stack:** Built with React, Tailwind CSS, and Framer Motion for butter-smooth scroll animations.
- **📱 Fully Responsive:** Optimized across mobile, tablet, and ultra-wide displays.
- **💬 Interactive CTAs:** Direct integration with WhatsApp API and `tel:` action triggers.
- **🔍 SEO Friendly:** Structured semantic HTML5 tags and meta header optimizations.

---

## 🛠️ Tech Stack

- **Frontend Framework:** [React.js](https://reactjs.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
